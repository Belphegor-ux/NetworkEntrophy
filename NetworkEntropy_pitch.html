The Problem

Not all links are equal.
Which ones hold the network together?

Infrastructure fails at the edges

A handful of transmission lines, when lost, cascade into wide-area blackouts. Operators need to know which links carry the structural load.

Node importance ≠ edge importance

Decades of work rank critical nodes. The bridges, bottlenecks, and articulation links between them are under-served.

Real grids are messy

Benchmarks (Karate, Jazz) are toys. Authentic infrastructure has bridges, long line-segments, and irregular degree — and breaks differently.

Core Method · Dismantling

Rank edges → remove in order → watch the giant component collapse

  • Each metric scores every edge for structural criticality.
  • Edges are removed highest-rank-first ("dismantling").
  • Track the Relative Giant Component (RGC) after every cut.
  • The AUC of the RGC curve summarizes effectiveness.
  • Lower AUC = the metric finds critical links faster.

The Toolkit · 9 Edge Metrics, 3 Families

One standardized schema. Nine ways to rank an edge.

Topological

  • LDC — degree(u)·degree(v)
  • Jaccard — neighbour overlap
  • LKS — k-shell(u)·k-shell(v)

Collective Influence ×4

  • skin / body — ball shell vs volume, ℓ=3
  • av / mul — edge from node scores

Resolves the ambiguous "∂Ball" definition by computing both readings.

Entropy / Local Betweenness

  • LLBCe — local link betweenness
  • LLBMEe1 — + mapping entropy

Subset betweenness on Γ(e)={u,v}∪N(u)∪N(v) — no subgraph cutting.

Canonical DataFrame: columns i, j, <metric>… — every metric, every dataset, one schema.

The Twist · Static vs. Iterative

Recompute the ranking after every removal

Static

Rank once on the intact network, then remove in that fixed order. Fast, but blind to how the topology changes mid-collapse.

Iterative

After each cut, the surviving graph is re-scored and the next most-critical edge is chosen afresh — adaptive dismantling that tracks the shifting structure.

Because mid-dismantling metric values aren't comparable across steps, the iterative pipeline records each edge's 1-based removal order, not its raw score.

Finding 02

The winning metric depends on the network's regime

Infrastructure & sparse, structured graphs

LLBMEe1 / LLBCe dominate. Local-betweenness entropy captures the bridges and bottlenecks that carry flow across a physically constrained topology.

Dense social & collaboration graphs

Jaccard leads. Where communities overlap heavily, low neighbour-overlap pinpoints the inter-cluster bridges whose removal shatters connectivity.

There is no single universal metric — but entropy-based local betweenness is the most reliable choice for the infrastructure problem that motivated this work.
